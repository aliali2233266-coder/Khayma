# تكسي الخيمة — Khayma Taxi
Prototype Flutter أولي قابل للبناء كـ APK.

## التشغيل
1. ثبّت Flutter 3.x وAndroid Studio.
2. افتح المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
   flutter run
4. لبناء APK:
   flutter build apk --release

ملحوظة: هذه نسخة Prototype محلية ببيانات Mock؛ الخرائط وOTP والدفع والتتبع الحقيقي والـBackend لم تُربط بعد.
